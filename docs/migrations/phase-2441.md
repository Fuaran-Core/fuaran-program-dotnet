# Migration — Phase 2441: a witness declares how its refusals read

Rides the `0.14.0` draft slot (`STABILITY.md`; `DECISIONS.md` D60). Breaking for every consumer
that **constructs** an `ActionWitness` with a full record literal: the record gains one member and
the literal fails with FS0764. A consumer that only runs programs through a witness it did not
construct changes nothing. No shape of `ActionView`, `LeafOutcome`, `BoundedOutcome`,
`BoundedDiagnostic` or `Trace` moves, and no refusal token moves.

## What changes

| Before (0.14.0 as Phase 2440 left it) | After |
|---|---|
| `ActionWitness` = `{ View; Lower; Describe; Encode; Decode; Substitute; Placeholders }` | plus `Refusals: RefusalReading` |
| — | `RefusalReading = Continues \| Halts` in `Fuaran.Program.Bounded` |
| a refusal is a diagnostic the sequence carries on past, at every witness | at a witness declaring `Continues`: exactly that, byte for byte |
| — | at a witness declaring `Halts`: every refusal HALTS as a guard does, and `BoundedActions.run` / `runTraced` / `runInert` settle a halted run to the entry store with no effect, diagnostics kept, the refusal last |
| a guard halt keeps the prefix's effects and the store as of the halt | at a `Continues` witness: unchanged; at a `Halts` witness: settled the same way as a refusal |

## The diff, per file

**Every witness that keeps today's reading** (the UI adapter, every domain whose refusals are
diagnostics):

```diff
 Action =
     { View = view
       Lower = lower
       Describe = describe
       Encode = encode
       Decode = decode
       Substitute = substitute
-      Placeholders = placeholders }
+      Placeholders = placeholders
+      Refusals = RefusalReading.Continues }
```

**A witness over an actuator, whose plans must be all or nothing:**

```diff
       Substitute = substitute
-      Placeholders = placeholders }
+      Placeholders = placeholders
+      Refusals = RefusalReading.Halts }
```

and then the placement no longer needs to read the outcome's diagnostics for refusals: a run that
refused anything, or met a guard that did not hold, returns `Halted = true` with `Effects = []` and
the entry `Store`, and a run with `Halted = false` met no refusal. A placement rule of the form
"perform the plan only if no diagnostic is a refusal and the run did not halt" reduces to "perform
the plan if the run did not halt":

```diff
-match outcome.Diagnostics |> List.choose refusalOf, outcome.Halted with
-| [], false -> perform outcome.Effects
-| [], true -> refuse [ "halted" ]
-| reasons, _ -> refuse reasons
+if outcome.Halted then refuse (outcome.Diagnostics |> List.choose refusalOf)   // the refusal is last
+else perform outcome.Effects
```

**A reader of a halted outcome at a `Halts` witness** must not expect the store as of the halt: it
is the entry store. Nothing changes for a reader at a `Continues` witness.

## Verification

1. `pwsh ./run.ps1` — format, pins, build, every suite, the Fable parity leg.
2. `pwsh ./proofs/check.ps1` — `BoundedFold.fst` checks with section 12 (`halting_run_all_or_nothing`,
   `halted_ends_with_refusal`, `continuing_run_is_fold`), extracts byte-identically to the committed
   oracle, and the differential host agrees at both toy witnesses over the whole corpus.
3. A consumer's own test that one program run through its witness at `Continues` and at `Halts`
   differs only when a refusal or a halt occurs — `tests/Fuaran.Program.Tests/HaltingRefusalTests.fs`
   is the shape.

## Rollback

Revert the commits of Phase 2441 together (proofs, feature, docs). The oracle under
`proofs/oracle/BoundedFold.fs` is regenerated by the proof leg and must move with the model; nothing
on the wire, in the demanded document or in the signed envelope moved, so no re-signing follows a
revert.
